# Note Contract

Use this note shape unless the user explicitly requests something else:

`Status: ... Need: ... Next: ... Attempts: ...`

## Status

- State the current IX status as of the latest reliable source.
- Prefer present-tense operational wording.
- Good:
  - `Pending Part 1; Prepare IX Part 2 is held because Part 1 is still open.`
  - `Part 2 was submitted on 8/8/2025 and is still held for Field Corrections Required.`
  - `Prepare IX Part 2 is not submitted and is held for Missing Placard.`
- Avoid:
  - vague history dumps
  - unsupported claims like `utility rejected` or `transformer upgrade` unless directly stated

## Need

- Say what is missing or blocked right now.
- Keep it concrete and short.
- Good:
  - `Customer signature is still needed on the interconnection documents.`
  - `Placard installation and proof photos are still needed.`
  - `The utility transformer upgrade must be completed before Part 2 can finish.`

## Next

- State the next operational move, not every future milestone.
- Good:
  - `Resolve the withdrawn vs. active application, submit or reactivate the correct Part 1 file, then resume Part 2.`
  - `Finish the field work, submit corrected photos or documents, and wait for utility review.`
  - `Follow up with the utility until the upgrade is complete, then continue Part 2 review.`

## Attempts

- Count documented attempts against the current blocker, not raw task-log volume.
- If the need is a customer signature, count signature/customer outreach attempts. If the need is field correction proof, count scheduling, correction, photo, or proof attempts. If the need is utility review, count utility follow-ups.
- Prefer the currently active blocker or the most relevant two blockers.
- Include dates.
- If there are many touches, list the most recent dates and collapse older ones.
- Good:
  - `customer signature/document retrieval: 6 documented attempts (2/26/2026, 3/18/2026, 3/30/2026, 4/3/2026, 4/6/2026, 4/13/2026)`
  - `field correction/proof: 9 documented attempts (3/8/2026, 3/16/2026, 3/22/2026, 3/30/2026, 4/3/2026, 4/6/2026 (+3 earlier))`

## Examples

### Part 1 still open

`Status: Pending Part 1; Prepare IX Part 2 is held because Part 1 is still open. Need: Confirm the correct Part 1 application and CAD package so Part 1 can move forward. Next: Resolve the withdrawn vs. active application, submit or reactivate the correct Part 1 file, then resume Part 2. Attempts: application/CAD resolution: 6 documented attempts (2/26/2026, 3/18/2026, 3/30/2026, 4/3/2026, 4/6/2026, 4/13/2026)`

### Transformer upgrade

`Status: Part 2 is active and currently held for Transformer upgrade pending. Need: Utility transformer upgrade must be completed before Part 2 can finish. Next: Follow up with the utility until the upgrade is complete, then continue Part 2 review. Attempts: utility transformer-upgrade follow-up: 14 documented attempts (3/8/2026, 3/16/2026, 3/22/2026, 3/30/2026, 4/3/2026, 4/6/2026 (+8 earlier))`

### Field corrections

`Status: Part 2 was submitted on 8/8/2025 and is still held for Field Corrections Required. Need: Complete the field correction work and collect whatever proof the utility is waiting on. Next: Rescheduled on 05/05, then resubmit the corrected package for utility review. Attempts: field correction/proof: 9 documented attempts (3/13/2026, 3/17/2026, 3/24/2026, 4/1/2026, 4/2/2026, 4/9/2026 (+3 earlier))`
